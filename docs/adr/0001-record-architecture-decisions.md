# ADR 0001: Record architecture decisions

## Status
Accepted

## Context
The build protocol requires that every architectural decision of consequence is
recorded as a short architecture decision record. This is the first record and
establishes the practice.

## Decision
We record decisions as numbered Markdown files in `docs/adr/`. Each has a
status, the context that forced the decision, the decision itself, and the
consequences. British English. No em dashes.

## Consequences
A reader can reconstruct why the system is shaped as it is without archaeology
through the commit history.
